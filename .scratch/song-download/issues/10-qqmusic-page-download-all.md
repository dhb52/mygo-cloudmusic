# qqmusic：整张专辑、整个歌单与播放队列的下载入口

Status: resolved
Repo: `~/Source/qqmusic`（`dhb52/qqmusic`）
Blocked by: 06, 07

## 目标

把 09 的决定用在插件上：v1 的批量 = 单曲右键（06）+ **页级入口**，不做勾选列多选。页级入口把当前列表整批送进同一套弹窗与批次语义。

## 改动

- 专辑详情页、歌单详情页的标题区加「下载全部」按钮（`actionPill`，`settings_view`/页面头部现有的按钮风格），播放队列页同理（「下载队列」）。
- 列表就绪且有曲目时才渲染；`DownloadAvailable` 为假、或列表还在加载时不渲染。
- 点击时把该页当前的完整曲目列表交给 06 里的 `beginDownload(tracks)`：一次码率选择、聚合可用性（「无损（FLAC）· 3/5 首可用」）、逐条任务、跳过清单。曲目过多时给出上限（沿用宿主 `Download` 的 8192 上限，超过则在插件侧提示并拒绝）。
- 已在进行中的同一批（同一 token）不重复入队：按钮在批次进行中显示「下载中…」并禁用（按 `DesktopSettings.Downloads` 里 `Phase == running` 判断）。

## 验收

- `go test ./...` 通过。
- 手工：专辑页「下载全部」→ 弹窗显示该专辑的曲目数与聚合可用性 → 选无损 → 设置窗任务区逐条完成；期间按钮显示「下载中…」。
- 手工：歌单页与播放队列各一次；曲目里有不可用的（无会员/下架）时跳过清单正确。
- 单测：聚合行文案（全可用 / 部分可用 / 全不可用）与上限拒绝。
